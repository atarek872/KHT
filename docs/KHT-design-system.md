# KHT — Design system v1

الحالة: مقترح تصميم للمراجعة، دون تنفيذ واجهات أو اختيار منصة بيع.

## 1. الاتجاه الإبداعي

**BLACK. WHITE. LINE.** متجر ملابس بطابع استعراضي؛ الصورة تعرض القَصّة والخامة، والخط الأبيض يربط البراند بتجربة التصفح. يشمل تيشرتات، سوت، وبناطيل.

العنصر البصري الرئيسي: صورة حملة كبيرة تبرز الخط على القطعة، مع امتداد أبيض واحد في المساحة المحيطة. العناوين كبيرة، ومسار الوصول للمنتج مباشر. شكل الخط النهائي يُشتق من صور الملابس واللوجو عند توفيرهما؛ لا يُفترض شكل العلامة من الوصف وحده.

الرئيسية والحملات داكنة بنسبة تقريبية 70% أسود/فحمي، 20% أبيض، 10% رمادي. هذه نسبة إحساس عام وليست قيدًا على كل شاشة؛ صفحات المنتجات والسلة وإتمام الطلب فاتحة لإظهار الملابس السوداء وتسهيل القراءة.

لا ألوان إضافية، ولا gradients، ولا ظلال زخرفية أو تأثير زجاجي. الأخطاء والنجاح يظهران بنص واضح وأيقونة مناسبة وحدود مميزة؛ لا نعتمد على الأحمر أو الأخضر. ألوان مزود الدفع الخارجي، إن ظهرت مستقبلًا، لا تتحول إلى ألوان للهوية.

`#8A8A8A` لا يُستخدم للنصوص الصغيرة المهمة على الخلفية الفاتحة؛ البديل `#666666`. الفواصل الخفيفة للزينة فقط وليست الحدود الوحيدة اللازمة للتعرف على حقل أو اختيار.

## 3. الخطوط والكتابة

اقتراح الخطوط: **Barlow Condensed** للعناوين الإنجليزية والحملات، و**IBM Plex Sans Arabic** للنص العربي والواجهة. هذه اختيارات تصميم مقترحة؛ لم تُثبت أو تُحمّل ملفات خطوط. اللوجو يستخدم الأصل المعتمد عند توفره، ولا يُعاد تصميمه كنص بديل نهائي.

| المستوى | Desktop | Mobile | الوزن والدور |
| --- | --- | --- | --- |
| عنوان الحملة اللاتيني | 112–144 px | 56–72 px | 600، سطر أو سطران، line-height 0.95 |
| عنوان الحملة العربي | 64–80 px | 36–44 px | 600، line-height 1.2 |
| عنوان الصفحة | 48 px | 32 px | 600 |
| عنوان القسم | 32 px | 24 px | 500–600 |
| اسم المنتج | 20 px | 18 px | 500 |
| السعر | 22 px | 20 px | 600 |
| نص الواجهة والوصف | 16 px | 16 px | 400، line-height 1.6 |
| المعلومات المساندة | 14 px | 14 px | 400 |
| الأزرار | 16 px | 16 px | 500 |

لا تمديد للحروف العربية. العناوين اللاتينية المضغوطة بلا تباعد مبالغ فيه. الأحرف الكبيرة محصورة في KHT وعبارات الحملة مثل BLACK. WHITE. LINE. وSHOP DROP 001؛ التسميات العادية تكتب بشكل طبيعي.

الواجهة العربية RTL ومحاذاتها لليمين؛ النصوص الإنجليزية وأكواد المقاسات وأرقام الطلبات تحتفظ باتجاه LTR داخلها. اتجاه أسهم التنقل ينعكس بحسب اللغة، والصور واللوجو لا تُعكس. طول الوصف المستهدف 45–65 حرفًا في السطر.

الصوت الكتابي قصير ومحدد: «اختار مقاسك»، «أضف للسلة»، «متابعة لإتمام الطلب». لا ادعاءات عن الخامة، الندرة، الشحن المجاني أو آراء العملاء دون بيانات فعلية.

## 5. قواعد الخط المميز

- **خط الحملة:** امتداد واحد أبيض بسمك مقترح 3–4 px على Desktop و2–3 px على الهاتف، يتبع اتجاه الخط الموجود فعلًا في الصورة. يبقى خارج العناوين وأزرار التفاعل ولا يضاف إلى خامة المنتج لإيهام العميل بتفصيل غير موجود.
- **خط الانتقال:** فاصل ممتد بين نهاية الحملة وبداية التسوق؛ يستخدم مرة في الانتقال الأساسي، دون زخرفة كل قسم.
- **خط التفاعل:** يظهر بطول 24–40 px وسمك 2 px عند Hover أو تركيز رابط/صورة منتج، في منطقة خالية من الصورة. يعكس إلى الأسود فوق الخلفيات الفاتحة.
- **خط التحميل:** حركة واحدة مستمرة داخل مساحة انتظار فعلية فقط. لا شاشة مقدمة تؤخر الدخول للموقع، ولا نسبة تقدم وهمية.
- الخط الزخرفي لا يحمل معلومة منفردًا، ولا يلتقط النقر، ولا يلتبس مع عنصر قابل للسحب.

## 6. المكونات وحالاتها

| المكون | الشكل والسلوك |
| --- | --- |
| Header | KHT + تسوق + الإصدار الحالي + عن KHT؛ البحث والسلة واضحان دائمًا؛ القائمة مختصرة على الهاتف |
| زر رئيسي | أبيض على الداكن، أسود على الفاتح؛ إجراء رئيسي واحد داخل كل مجموعة قرار |
| زر ثانوي | شفاف، حد واضح 1 px، بلون النص؛ يستخدم للرجوع أو متابعة التسوق |
| رابط نصي | خط سفلي عند Hover، ومؤشر تركيز مستقل؛ روابط الوصف والسياسات مسطرة دائمًا |
| بطاقة منتج | صورة 3:4 ثم الاسم والسعر واللون/المقاسات المتاحة؛ الصورة والاسم يفتحان نفس المنتج |
| محدد المقاس | مربعات بحد ظاهر؛ المختار معكوس اللون؛ غير المتاح مشطوب ومعه وصف «غير متاح» |
| اختيار اللون | مربع عينة مع اسم مكتوب وإطار اختيار؛ يحذف التحكم إذا لم توجد بدائل، مع إبقاء اسم اللون |
| معرض الصور | أمامي، خلفي، تفصيلة الخط والخامة، ثم صورة على موديل؛ تكبير قابل للإغلاق |
| حقل إدخال | Label ثابت فوق الحقل، نص مثال مساعد عند الحاجة؛ رسالة الخطأ أسفل الحقل |
| فلتر | خيارات قليلة ذات صلة؛ الفلاتر النشطة قابلة للإزالة وزر «مسح الفلاتر» |
| Accordion | عنوان وتحكم +/− ومساحة لمس كاملة، بلا صندوق مزخرف |
| السلة الجانبية | تفتح بعد نجاح الإضافة؛ صورة القطعة، المقاس، الكمية والسعر، وإجراء إتمام الطلب |
| ملخص الطلب | إجمالي القطع، الخصم إن وجد، التوصيل، أي رسوم مطبقة، ثم الإجمالي النهائي |
| رسالة حالة | أيقونة + نص يحدد النتيجة والخطوة التالية؛ تظل الأخطاء ظاهرة حتى المعالجة |

حالات التحكم المشتركة:

- **Default:** نص وحد واضحان.
- **Hover:** تغير محايد بسيط؛ لا تحريك للبطاقة أو تغيير أبعادها.
- **Focus:** إطار 2 px مع فراغ 3 px؛ حلقة مزدوجة أبيض/أسود عند المرور فوق صور مختلفة الدرجات.
- **Pressed:** تغير سطح قصير، بلا تغيير موضع النص.
- **Disabled:** سطح رمادي ونص يوضح سبب عدم الإتاحة؛ لا نكتفي بخفض الشفافية.
- **Loading:** يحتفظ الزر بعرضه، ويظهر «جارٍ الإضافة…» أو «جارٍ تأكيد الطلب…» ويمنع التكرار.
- **Success / error:** رسالة فعلية من نتيجة العملية؛ «تمت الإضافة للسلة» أو «تعذر إضافة القطعة. حاول مرة أخرى».

## 7. الصور والحركة

تصوير الحملة داكن بإضاءة جانبية تظهر حدود الملابس السوداء والخط الأبيض. صورة كاملة أو قصّة مدروسة، دون خلفية تقنية أو أشكال ثلاثية الأبعاد. تصوير الكتالوج محايد على `#EAEAE7` مع نسب حجم ومحاذاة متسقة. ألوان المنتج وخامته تُعرض بأمانة، دون فلتر يخفي التفاصيل.

معرض المنتج يحتفظ بكامل القطعة قدر الإمكان. صور الحملات لها قص مستقل للهاتف يحفظ الوجه والملابس؛ لا نضع نصًا داخل ملف الصورة. لا تستخدم صورًا عشوائية كمنتجات فعلية.

الحركة المقترحة: 160 ms للتفاعل البسيط، 240 ms للسلة/القائمة، وحتى 600 ms لكشف خط الحملة مرة واحدة. حركة الخط لا تمنع القراءة. لا parallax أو تمرير إجباري أو carousels تلقائية. عند تقليل الحركة تظهر الحالات فورًا ويستبدل الخط المتحرك بمؤشر انتظار ثابت مع نص.

## 8. سهولة الاستخدام ومعايير مراجعة التصميم

- استهداف تباين 4.5:1 للنص العادي و3:1 للنص الكبير والتحكم؛ تفحص الأزواج الفعلية وقت التنفيذ، ولا تعتبر هذه الوثيقة إثبات اختبار.
- جميع إجراءات الشراء تعمل بلوحة المفاتيح والهاتف. لا معلومات ضرورية تظهر بالـHover فقط.
- النوافذ والسلة تحصر التركيز أثناء فتحها، لها زر إغلاق واضح، وتعيد التركيز إلى مصدر الفتح.
- إضافة منتج وتغير عدد السلة يعلنان لقارئ الشاشة؛ الأخطاء مرتبطة بحقولها.
- شريط الشراء الثابت على الهاتف يترك مساحة للمحتوى ومنطقة أمان الجهاز، ولا يغطي المقاسات أو الرسائل.
- الصور لها مساحة محجوزة ووصف مناسب؛ صورة الـHero تظهر دون انتظار حركة افتتاحية، وباقي الصور تحمل عند الحاجة.

## 9. مراجعة الاتجاه أمام الـbrief

تم اعتماد صرامة المساحات والمكونات المسطحة من minimalist-ui، واستبعاد الباستيل والـgradients وشبكة bento والخط serif والحركة على كل قسم لأنها لا تخدم هوية KHT. تم الاحتفاظ بالأسود والأحرف الكبيرة والسهم في الحملة لأن المستخدم طلبها صراحة، مع ضبط استخدامها.

التميّز في علاقة خط القطعة بخط الحملة. العناصر الباقية هادئة، والمنتجات والأسعار والمقاسات واضحة. المرجع المرئي الذي أُشير إليه في الطلب لم يُرفق؛ هذه النسخة مبنية على وصف الهوية فقط.
